PWA STANDALONE GUIDE

零安裝快速釘選：以原生視窗運行 Web 終端

透過現代瀏覽器支援的 Progressive Web Apps (PWA) 規範，無須下載任何執行檔，即可將看盤終端直接安裝至系統桌面或 Dock，享受無網址列的純淨原生體驗。

🪟 Windows (Google Chrome / Microsoft Edge)
  1. 於瀏覽器點擊上方 「立即啟動免安裝 Web 終端」 進入看盤工作區。
  2. 觀察瀏覽器頂部網址列右側，點選 「電腦圖示（安裝 ProStock Analyzer）」。
  3. 於彈出確認視窗點選 「安裝」。
  4. 系統將自動於桌面與開始選單建立獨立應用程式圖示，爾後雙擊即可秒開原生獨立視窗。
🍎 macOS (Safari / Chrome)
  1. 於 Safari 或 Chrome 開啟 「免安裝 Web 終端」。
  2. Safari：點選上方系統選單列之 「檔案」➜「加入 Dock」。
  3. Chrome：點選網址列右側之 「安裝」 圖示按鈕。
  4. 終端將常駐於 Mac Dock 應用列，享受全螢幕視窗與獨立記憶體進程。

作業系統安全憑證與信任授權指引

本專案為非營利之獨立開源專案，發行版二進位未包含商業機構每年收費之數位簽章。初次執行時 macOS 或 Windows 系統可能會觸發安全性防護提示，此為標準防護機制。

macOS Gatekeeper 隔離屬性解除

若 macOS 提示「檔案已損毀，您應該將其丟到垃圾桶」，此為 Apple 對網路下載未簽章軟體預設套用之 com.apple.quarantine 隔離標籤。

終端機快速授權指令（建議方式）：
xattr -cr "/Applications/ProStock Analyzer.app"
執行後即可徹底清除隔離旗標並正常啟動。亦可於「系統設定」➜「隱私權與安全性」點擊「仍要打開」。
Windows Defender SmartScreen 授權

微軟 Windows Defender 對所有發行時間較短或未購置 EV 企業簽名之新開源程式，預設將顯示藍色防護攔截畫面。

簡易信任步驟：
  1. 於「Windows 已保護您的電腦」提示畫面中，點擊 「其他資訊」 文字連結。
  2. 視窗右下角將顯現 「仍要執行」 按鈕，點擊即可順利啟動安裝。

Q1：ProStock Analyzer 的收費機制與商業模式為何？ 100% FREE

ProStock Analyzer 為純粹之開源軟體專案，所有核心功能（包含即時行情檢索、多週期圖表、五檔撮合深度、Volume Profile 籌碼分佈及 T+2 模擬交易）全面免費開放，無任何付費會員門檻、廣告投放或隱藏資費。

Q2：即時行情資料來源與連線架構如何運作？ MARKET DATA

系統對接主流公開金融行情 API（涵蓋台灣證券交易所 TWSE、櫃買中心 TPEx、Yahoo Finance 與美股即時數據），行情更新由客戶端直連請求，具備智慧容錯輪換機制，確保連線穩定與實時報價精確。

Q3：Web 免安裝版與 macOS / Windows 桌面原生版的功能是否完全一致？ CROSS-PLATFORM

兩者功能核心 100% 相同。Web 版具備跨裝置隨開即用、零系統警示之優勢；桌面原生版則進一步整合本機 GPU 硬體管線加速與離線暫存能力，使用者可依自身工作流與硬體偏好自由選擇。

Q4：個人自選股、歷史畫線與指標參數如何保證不遺失？ DATA SOVEREIGNTY

本專案嚴格貫徹「數據本地主權」原則。所有自選清單、指標參數調整與技術畫線資料，皆持久化存儲於使用者設備之本地資料庫中，即使版本升級或瀏覽器重啟亦不會遺失，完全免除個資外洩之疑慮。

Q5：桌面客戶端發布新版本時，是否有自動檢查更新機制？ AUTO UPDATER

客戶端於啟動時將自動與 GitHub Releases 官方伺服器進行版本輪詢比對。若偵測到新版本，右上方將顯示更新提示與直載按鈕，使用者點擊即可完成升級，原自選名單與技術畫線無縫繼承。
