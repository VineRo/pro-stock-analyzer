桌面版安裝說明（與系統警告解法）

老實說，因為這是我自己寫的開源軟體，沒有每年給蘋果和微軟付好幾萬元的商業憑證保護費，所以第一次打開時，系統一定會跳出嚇人的警告。請依照以下方式一秒解開：

🍎 Mac 使用者安裝步驟
  1. 點擊上方 「下載 Mac 版 (.dmg)」。
  2. 下載完成後，點兩下開啟 .dmg 檔案。
  3. 將 ProStock Analyzer 圖示拖移到右側的 Applications (應用程式) 資料夾。
  4. 在「應用程式」中點擊圖示打開。
若系統提示「檔案已損毀，您應該將其丟到垃圾桶」： 這是 Apple 對網路下載、沒有付年費買商業憑證的開源軟體下的「隔離標籤」，檔案本身完全沒有壞！
⚡ 最推薦的 1 秒解除法（終端機指令）：
打開 Mac 內建的「終端機 (Terminal)」，複製下面這行指令貼上按 Enter，就能一秒解鎖直接打開：
xattr -cr "/Applications/ProStock Analyzer.app"
（如果不想要打指令，也可以直接使用上面的「免安裝網頁版」，完全不會跳警告）
🪟 Windows 使用者安裝步驟
  1. 點擊上方 「下載 Windows 版 (.exe)」。
  2. 點兩下執行下載好的安裝檔（ProStock-Analyzer-Setup.exe）。
  3. 依照畫面提示點擊 「下一步」，安裝完成會在桌面生成啟動捷徑。
  4. 在電腦桌面找到 ProStock Analyzer 捷徑，點擊啟動！
若跳出藍色「Windows 已保護您的電腦」且找不到執行按鈕： 別緊張，微軟對沒有花大錢買企業簽名的開源新軟體都會先跳這個視窗。
解法超級簡單：
點擊視窗上的「其他資訊」文字連結，右下角就會出現「仍要執行」按鈕，點下去就能順利安裝啟動了！

常見問題 FAQ

解答你可能遇到的疑問

Q1：這個軟體下載後需要收費嗎？以後會收費嗎？

完全不用！我自己就是開發者跟日常交易人，做這套工具就是想給自己和朋友一個乾淨順手的看盤環境，全功能免費開放，沒有 VIP 限制也沒有任何惱人的廣告。

Q2：未來有新版本，我需要每次都重新回來這個網頁下載嗎？

不用！軟體打開時會自動確認有沒有新版本。如果有新版，點一下按鈕就會幫你下載好，原先存好的自選股跟畫線也都不會消失。

Q3：如何確認下載的檔案是安全無毒的？

這套軟體的原始碼在 GitHub 完全開源，每一行都公開透明。網站上也提供 SHA-512 校驗碼供比對，所有安裝包都是由 GitHub 官方伺服器自動建置打包，絕無任何廣告或惡意代碼。

Q4：Windows 安裝時若跳出 SmartScreen「已保護您的電腦」該怎麼辦？

這是微軟 Windows 對所有未付費購買商業簽名的獨立開源軟體之標準防護提示。只要點擊視窗上的「其他資訊」，再按「仍要執行」即可啟動。

Q5：Mac 打開時提示「檔案已損毀，您應該將其丟到垃圾桶」該如何解決？

這是 Apple macOS 對開源軟體的例行攔截，檔案本身完全無損。解法只要 1 秒：打開 Mac 的「終端機 (Terminal)」，貼上指令 xattr -cr "/Applications/ProStock Analyzer.app" 按 Enter，就能永久解除隔離正常打開！或者直接使用免安裝網頁版。
