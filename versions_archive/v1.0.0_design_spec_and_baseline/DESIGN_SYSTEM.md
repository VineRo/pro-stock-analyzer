## 1. 設計風格深度剖析

市場上常見的金融股票工具通常分為三大流派：

| 流派風格 | 代表產品 | 優勢 | 致命劣勢 |
| :--- | :--- | :--- | :--- |
| **傳統終端流** | Bloomberg, Wind, 早期大智慧 | 資訊密度極大、按鍵反應極快 | 視覺壓抑、黑底黃綠橘色反差刺眼、學習曲線陡峭，對非機構用戶極度不友善 |
| **消費型簡約流** | Robinhood, Cash App, 傳統大眾券商App | 介面極簡、大量空白、視覺親和力高 | 圖表區域窄小、缺乏深度畫線與多指標疊加能力、無法支撐專業技術分析 |
| **現代專業技術分析流** | **TradingView, Koyfin, Webull Desktop** | **沉浸式深色、圖表佔比極大、工具隨選即用、視覺雜訊近乎為零** | 若缺乏新手引導，初學者容易迷失在海量指標與按鈕中 |

### 🏆 本產品的最佳風格定位：【現代深色高密度專業風（Modern Dark Pro）】
我們選定此風格的核心論據：
1. **長時間看盤的視力保護（Ergonomics）**：技術交易者平均盯盤超過 3-6 小時。採用深冷色調（深藍灰基底 `#131722`）能最大幅度減少螢幕白光直射造成的視疲勞，遠勝淺色或純黑 `#000000`。
2. **圖表為視覺主體（Zero-Noise Canvas）**：背景、格線與框線皆退居次要層次（5%~12% 低對比度），讓多條趨勢線、K 線蠟燭與技術指標的色彩能第一時間被大腦捕捉。
3. **數據精確感（Sub-pixel Precision）**：利用 1px 俐落分割線、細緻的向量圖標與等寬數字排版，營造毫秒級金融工具的嚴謹度與可信度。
4. **小白親和的漸進式揭露（Progressive Disclosure）**：在專業底層之上，透過「白話文智慧診斷條」與「指標速成百科」，讓新手不被複雜介面嚇跑，逐步成長為專業交易者。

## 2. 核心設計哲學與人機原則

1. **資訊為王，裝飾退後（Content Over Chrome）**：
   - 介面框架（邊框、按鈕、背景）的存在是為了「襯托行情數據」，不得喧賓奪主。禁止使用過度誇張的大漸層、厚重立體投影或無意義的裝飾插圖。
2. **零抖動與穩定預期（Zero-Jitter Interface）**：
   - 數字跳動時欄位寬度不可忽大忽小（必須鎖定等寬數字）。
   - 圖表縮放、平移時必須具備平滑慣性阻尼，避免畫面跳幀與殘影。
3. **精準反饋與防手抖（Confidence in Every Click）**：
   - 點擊畫線必須有磁吸錨點（Magnet snap-point）提示，讓使用者清楚知道自己正吸附在 High、Low 還是 Close。
4. **漸進式專業化（Beginner-to-Pro Continuum）**：
   - 預設提供最優化配置（例如預載 5/10/20MA、成交量與多空智慧短評），讓新手開箱即用；同時保留自定義指標、參數微調與多窗格分屏給高階玩家。

### 3.2 多空漲跌語義色盤（雙文化適應矩陣）

金融介面最大的陷阱是忽視不同文化地域對「紅綠」的認知相反。系統必須提供一鍵全局切換，並保留中性色。

| 交易狀態 | 國際標準模式（美股/加密/外匯） | 傳統亞洲模式（台股/陸股/日股） | 象徵心理 |
| :--- | :--- | :--- | :--- |
| **多頭 / 上漲（Bullish）** | `#089981` (翡翠綠 Emerald) | `#f23645` (亮珊瑚紅 Crimson) | 充滿希望、向上噴發、獲利 |
| **空頭 / 下跌（Bearish）** | `#f23645` (亮珊瑚紅 Crimson) | `#089981` (翡翠綠 Emerald) | 警戒、向下修正、風險 |
| **平盤 / 中性（Neutral）** | `#787b86` (板岩灰 Slate Gray) | `#787b86` (板岩灰 Slate Gray) | 橫盤整理、多空觀望 |
| **上漲背景微光（Tint Up）** | `rgba(8, 153, 129, 0.12)` | `rgba(242, 54, 69, 0.12)` | 漲幅標籤背景底色 |
| **下跌背景微光（Tint Down）** | `rgba(242, 54, 69, 0.12)` | `rgba(8, 153, 129, 0.12)` | 跌幅標籤背景底色 |

> **色彩科學設計細節**：
> - 翡翠綠 `#089981` 避開了傳統容易刺眼的青綠色（`#00ff00`），具備高度飽和與可讀性，在黑底上即使細至 1px 依然清晰可辨。
> - 珊瑚紅 `#f23645` 避開了過暗的暗紅，確保暗色模式下不沉入底色。

## 4. 字體與數值排版規範（Typography & Numerical Rules）

### 4.1 字體棧（Font Stack）

金融軟體的數字需要絕對的精密感。字型應優先呼叫具備高品質數字符號的現代字型：

```css
/* 介面主字型 (UI & Body) */
font-family: -apple-system, BlinkMacSystemFont, "Trebuchet MS", Roboto, Ubuntu, "Helvetica Neue", "PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif;

/* 數值與報價專用字型 (Price, Tick, Volume, Timestamp) */
font-family: "SF Mono", "Roboto Mono", "JetBrains Mono", Menlo, Monaco, Consolas, monospace;
```

---

### 4.2 數值排版黃金鐵律：等寬數字（Tabular Figures）

> **重要原則**：
> 嚴禁在股票數值中使用非等寬比例數字。若數字 `1` 比 `8` 窄，當盤面每秒跳價數次時，小數點與整個數字區塊會發生劇烈的左右晃動（Jittering）。

#### CSS 強制宣告：
```css
.financial-number {
  font-variant-numeric: tabular-nums;
  font-feature-settings: "tnum";
  letter-spacing: -0.02em; /* 稍微縮減間距，提高緊湊感 */
}
```

#### 正負號與格式化規則：
- **上漲值**：必須顯示明確的正號 `+`，例如 `+12.50 (+2.45%)`，且與負號寬度對稱。
- **下跌值**：顯示負號 `-`，例如 `-8.30 (-1.12%)`。
- **千分位逗點**：所有大於 999 的成交量、市值與金額必須具備千分位分隔，例如 `1,425,800 張` 或 `$182,450.00`。
- **小數點位數固定**：台股價格小於 100 為小數點後 2 位；加密貨幣若小於 1 則格式化至 4~6 位，但同一欄位內位數必須縱向對齊。

## 5. 空間、網格與佈局架構（Layout & Density）

### 5.1 4px 網格原則

所有間距、圓角、按鈕高度與面板邊距皆嚴格遵守 **4px Base Grid**：
- `gap-1 (4px)`：極緊密元件內部間距（圖標與文字微調）
- `gap-2 (8px)`：按鈕內 Padding、工具列圖標間隔
- `gap-3 (12px)`：卡片內部資訊塊間距
- `gap-4 (16px)`：主面板內外 Padding、Modal 邊距
- `rounded-sm (2px / 4px)`：按鈕、輸入框微圓角（保持金融工具的精確感，**嚴禁大於 8px 的超大圓角**，以免浪費畫布空間）

### 5.3 緊湊度模式（Density Modes）

- **進階專業模式（Compact）**：
  - 邊界 Padding: 8px ~ 12px
  - 文字大小降為 11px ~ 12px
  - 畫布最大化，讓專業交易員在單一螢幕看清完整 1 年的 K 線細節與 4 個副圖。
- **新手舒適模式（Comfortable）**：
  - 邊界 Padding: 16px
  - 智慧診斷橫幅展開，展示完整的白話教學與多空分數計量條。

## 6. 圖表與畫布繪圖規範（Chart & Canvas Visual Spec）

### 6.1 K 線蠟燭體與成交量柱體

1. **蠟燭身（Body）與影線（Wick）幾何細節**：
   - 影線寬度：固定 `1px`，確保在任何解析度下銳利不發虛。
   - 蠟燭身最小寬度：`1px`（極度縮小時），標準寬度 `6px ~ 14px`。
   - 蠟燭間隙：蠟燭寬度的 25% ~ 30%（避免多根蠟燭粘在一起變成色塊）。
   - 空心/實心規則（可選配置）：
     - 預設模式：陽線與陰線均填滿實體色。
     - 美式空心模式：陽線（收盤 > 開盤）為空心邊框，陰線為實心填滿。
2. **成交量柱體（Volume Bars）**：
   - 成交量高度預設不超過主圖畫布下方的 18% ~ 22%，或獨立於副圖。
   - 柱體不透明度設為 `0.7` ~ `0.8`，避免成交量過於搶眼遮蔽下方 K 線。

---

### 6.2 網格線、刻度軸與十字游標（Crosshair）

1. **畫布格線（Grid Lines）**：
   - 樣式：虛線 `dash: [2, 4]` 或極淡實線。
   - 顏色：`rgba(255, 255, 255, 0.04)`（僅具微弱輔助對齊功能，絕不可干擾走勢閱讀）。
2. **十字游標（Crosshair）**：
   - 樣式：1px 細虛線 `dash: [4, 4]`，顏色 `#787b86`。
   - 游標軸標籤：游標落在 X 軸（時間）與 Y 軸（價格）時，刻度軸上的數值標籤以高亮深底膠囊浮現（深灰底 `#363a45` + 白色等寬字），並具備 2px 亮色邊框。
3. **最新價格標記線（Current Price Line）**：
   - 水平延展至右側座標軸的橫線。
   - 樣式：1px 點狀虛線，顏色依據當前漲跌動態變色（漲則綠/跌則紅）。
   - 右側座標刻度：以鮮豔實體色（漲綠/跌紅）高亮常駐，背景加上強烈對比白字。

---

### 6.3 即時動態懸浮看板（HUD - Heads Up Display）

位於主圖畫布左上角，隨游標移動即時更新：
```
[AAPL] • 日K • 2026-09-04  開: 232.40  高: 235.80  低: 231.10  收: 234.90 (+1.08%)  成交量: 48.2M
MA5: 231.20  MA10: 228.45  MA20: 225.10  BOLL(20,2): [238.10, 225.10, 212.10]
```
- **排版原則**：單行橫向流動排版，各數值以對應指標的顏色上色（如 MA5 數值為黃色，MA20 數值為粉紅色），讓使用者不需看線條圖例就能對應出具體數值。

---

### 6.4 磁吸模式（Magnet Mode）視覺錨點

當使用者啟動磁吸模式進行畫線時：
- 游標接近特定蠟燭周圍 15px 半徑時，自動出現一個直徑 6px 的**亮藍色微光圓環（`#2962ff` with 40% pulse shadow）**，精準鎖定在該蠟燭的最高點（High）、最低點（Low）或收盤價（Close）。
- 給予使用者強烈的「已精確捕獲」心智模型，完全消除手抖畫歪的挫折感。

## 7. 核心元件視覺規範（Component Guidelines）

### 7.1 畫線工具箱（Drawing Toolbar）

- **形式**：左側垂直懸浮或靠邊錨定工具條，寬度 44px。
- **圖標規格**：20x20px 精緻微線條 SVG 圖標（Stroke 1.5px）。
- **互動狀態**：
  - 常態（Default）：圖標色 `#787b86`，無底色。
  - 滑鼠懸停（Hover）：背景 `#2a2e39`，圖標高亮為 `#d1d4dc`，圓角 4px。
  - 選中啟動（Active）：背景 `rgba(41, 98, 255, 0.15)`，邊框 `1px solid #2962ff`，圖標高亮為 `#2962ff`。
- **子選單標記**：右下角帶有 3x3px 的極小三角形箭頭，長按或點擊右側呼出子工具（如斐波那契回撤、平行通道）。

---

### 7.2 自選股報價清單與 Tick Flash（跳價閃爍）

- **行高**：每支標的高 40px ~ 44px。
- **跳價閃爍動畫（Tick Flash）**：
  - 當最新價格跳動且高於上一筆時，整行背景或價格背景瞬間亮起 `rgba(8, 153, 129, 0.25)`（漲閃）並在 400ms 內平滑漸隱回原色。
  - 下跌跳價時瞬間亮起 `rgba(242, 54, 69, 0.25)`（跌閃）。
  - **原則**：閃爍範圍限於價格數值膠囊或極淡背景，不可整屏劇烈閃動造成刺眼。

---

### 7.3 智慧盤面診斷卡（Smart Summary Banner）

專為「技術分析小白」設計的關鍵橋樑元件：
- **視覺結構**：
  - **左側**：多空綜合評分儀表（圓環或計量膠囊，如 `85分 看多`）。
  - **中間**：白話文診斷摘要（如「股價站穩 5MA 之上，短線動能強勁；但 RSI 已達 78，短線需防超買回檔」）。
  - **右側**：一秒展開詳情按鈕與指標百科快捷連結。
- **色調**：採用半透明微光卡片（`#1e222d` 搭配細邊框 `#2a2e39`），多空分數依狀態給予綠/紅微弱呼吸燈效果。

---

### 7.4 新手速成指標百科彈窗（Education Modal）

- **視覺特徵**：打破死板的數學公式定義，採用「生活化比喻 + 雙欄圖解 + 買賣實戰要訣」。
- **色彩分區**：
  - 比喻小卡（黃色微光 Alert）：生活化比喻（如「MA 均線就像全班平均成績」）。
  - 核心技巧（綠色微光 Alert）：黃金交叉進場點、水上金叉。
  - 避坑指南（紅色微光 Alert）：背離逃頂、指標鈍化陷阱。

## 8. 動效與微互動（Motion & Interaction）

金融軟體重視「乾脆、零延遲、無拖沓」，動效時間嚴格控制在 **100ms ~ 250ms** 之間：

| 動效類型 | 持續時間 (Duration) | 緩動曲線 (Easing) | 設計意圖 |
| :--- | :--- | :--- | :--- |
| **按鈕點擊 / 工具切換** | 100ms | `cubic-bezier(0.4, 0, 0.2, 1)` | 接近瞬間觸發，反饋即時 |
| **彈窗 Modal 展開** | 180ms | `cubic-bezier(0.16, 1, 0.3, 1)` | 快速彈出且略帶自然微回彈 |
| **價格跳動 (Tick Flash)**| 閃爍 100ms, 漸隱 350ms | `ease-out` | 既能捕捉眼球，又迅速平息避免干擾 |
| **畫布平移與縮放** | 即時 (0ms) + 慣性阻尼 200ms | 手勢動量計算 | 達到如同 iOS 般順滑的手感 |
| **Tooltip 提示浮現** | 延遲 300ms, 淡入 120ms | `ease-in-out` | 避免滑鼠隨意劃過時到處亂彈浮窗 |

## 9. 無障礙與色弱支援（Accessibility & Colorblind Safe）

全球約有 8% 的男性存在紅綠色弱或色盲。在股票軟體中，單純依賴紅與綠極易造成致命的買賣判斷失誤。

### 色盲安全模式（Colorblind Accessibility Preset）
系統內建「紅綠色盲友善模式」時，自動切換至**藍橙光譜**：
- **上漲（Bullish）**：亮青藍色 `#00bcd4` 或 蔚藍色 `#2962ff`
- **下跌（Bearish）**：明亮暖橘色 `#ff9800` 或 金黃色 `#fbc02d`
- **符號雙重標記**：在數值旁邊一律強制加入箭頭圖標 `▲` 與 `▼`，不單純依靠色彩傳達資訊。

## 🎯 總結：給團隊的設計落實驗收標準（Checklist）

- [ ] **畫布優先**：主 K 線畫布在 1920x1080 下視野佔比必須大於 65%。
- [ ] **數字不晃**：所有報價、漲跌、指標數值均已啟用 `font-mono` 或 `tabular-nums`。
- [ ] **夜間友善**：暗色基底以 `#131722` 與 `#1e222d` 為主，無純白大區塊背景。
- [ ] **紅綠可切**：支援隨時在「美股標準（綠漲紅跌）」與「台陸標準（紅漲綠跌）」切換，且標籤文字與顏色同步聯動。
- [ ] **微光回饋**：價格跳動具備細膩的 300ms 漸隱微光，點擊畫線具備磁吸點自動吸附。
- [ ] **小白能懂**：專業技術數據旁皆附帶白話文解讀或生活化速成提示。
