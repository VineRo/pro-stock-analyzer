# v1.0.0 - 現代深色金融級設計規範與原型基線版

## 📌 版本概述
本版本為 ProStock Analyzer 專案的初始奠基版本，確立了金融級看盤軟體的視覺風格、色彩心理學規範與專業交易者動線。

## 📁 包含內容
- [DESIGN_SYSTEM.md](./DESIGN_SYSTEM.md)：金融級深色 UI 設計規範手冊（包含 60-30-10 配色比例、國際 vs 亞太雙紅綠體系、Typography 字階、資訊層級）。
- [UX_DESIGN_SPEC.md](./UX_DESIGN_SPEC.md)：看盤與交易者操作動線規格（涵蓋盤前 15 分鐘、盤中 4.5 小時、盤後 30 分鐘三階段核心流程與高頻快捷鍵布局）。

## 🎯 核心里程碑
1. 訂定 TradingView / 富途牛牛風格的高沉浸深色架構（底色 `#131722`、次底色 `#1e222d`、格線 `#2a2e39`）。
2. 確立全域雙色相系統切換（亞太紅漲綠跌 / 歐美綠漲紅跌）。
3. 建立初始 Electron + React + Tailwind + KlineCharts 應用架構。
