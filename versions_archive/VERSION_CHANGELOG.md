## 🌟 v1.2.0 (2026-09-05) - 元大證券風格升級、盤後交易與自適應優化版 [當前最新]

### 🎯 核心改動
1. **元大證券風格防黑邊 K 線圖**：
   - 徹底移除 `setLeftMinVisibleBarCount(5)` 與 `setRightMinVisibleBarCount(5)`，改用像素級滾動距離限制 `setMaxOffsetLeftDistance(50)` 與 `setMaxOffsetRightDistance(60)`。
   - 解決向右拖曳導致畫面 95% 呈現全黑空洞的 Bug，蠟燭永遠貼緊邊界並充滿畫布。
   - 將懸浮的黑色方塊 Tooltip 升級為元大證券投資先生標準的頂部平鋪資訊列（`TooltipShowType.Standard`），清晰平鋪「時間、開、高、低、收、漲幅、量」，零遮蔽圖表。
2. **實時時區、未開盤無波動與盤後交易即時追蹤**：
   - 導入國際時區時段判斷引擎 `getMarketSessionStatus`，涵蓋台股、美股、日韓、中港與歐洲各證交所。
   - **已收盤市場 (`CLOSED`)**：狀態標示為 `○ 已收盤`，Sparkline 波動圖呈現冷灰平靜線條（`#64748b`），絕不隨機追加虛假跳動點位。
   - **盤後交易市場 (`AFTER_HOURS`)**：美股 16:00-20:00 EDT 或台股盤後定價時段狀態即時顯示為 `● 盤後交易`（琥珀黃燈），實時追蹤盤後成交點位與波動。
   - **開盤交易市場 (`OPEN`)**：即時跳動顯示 `● 交易中`（翡翠綠燈）。
3. **全球大盤指數「今日領頭羊」下方選項遮蔽修復**：
   - 外層容器補齊 `min-h-0 flex-1`，解決 flexbox 計算溢出。
   - 地區篩選列改為自適應排版（`flex-wrap`），並直接整合快速排序按鈕（**依漲跌幅 / 依點位 / 依5日 / 依振幅** + 升降序箭頭）。
4. **頂部雙層工具列非全螢幕比例自適應**：
   - 四大分類按鈕於小螢幕自動縮寫為 `🇹🇼 台股`、`🇺🇸 美股`、`🌐 大盤`、`🪙 幣圈`。
   - 看盤操作列標的中文名稱在窄螢幕下自動隱藏；週期快捷鍵在小螢幕自動隱藏；籌碼分佈與雙屏分時按鈕自適應縮寫。
5. **劃線工具箱懸浮提示修復**：
   - 移除原生 title 屬性，提示框定點於工具箱右側外緣 10px，搭配 `pointer-events-none` 消除按鈕遮蔽。

## 🚀 v1.1.0 (2026-09-05) - 四大市場核心分類與旗艦分析工具整合版

### 🎯 核心改動
1. **頂部四大市場核心分類分頁**：
   - 提供「🇹🇼 國內股票」、「🇺🇸 國外股票」、「🌐 大盤指數」、「🪙 虛擬貨幣」四大獨立切換分頁，純淨高對比標籤，切換時圖表與自選側欄自動聯動。
2. **分析工具箱下拉整合**：
   - 收納智慧選股器、策略回測中心、個股基本面診斷、模擬交易沙盒、價格預警 5 大模組，解決頂部橫向擠壓問題。
3. **旗艦技術分析工具**：
   - 新增 Volume Profile 籌碼分佈圖、VWAP 成交量加權均價線、多週期雙屏同屏對比視圖。
4. **自選清單多群組管理**：
   - 支援建立多個自選群組與分市場精準管理。
