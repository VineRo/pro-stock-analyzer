## 🌟 v1.5.0 (2026-09-06) - K線圖資訊列移至畫布外防重疊、自選股新建立刻建庫、頂部按鈕雙核心精簡與全螢幕清理版 [當前最新]

### 🎯 核心改動
1. **K線圖資訊列與股票識別獨立外置（防重疊設計）**：
   - 徹底解決使用者在上下拉伸、縮放 K 線圖時，K 棒與指標線會遮蔽、重疊上方股票名稱與 OHLCV 文字的問題。
   - 將股票代號、名稱、市場標籤、週期標籤、即時 OHLCV、技術指標數值列與點擊固定的 K 棒 HUD 卡片，全部自圖表畫布內部抽離，搬遷至圖表畫布上方獨立的 DOM 資訊列（`bg-[#141720] border-b border-pro-border/80`）。
   - 圖表畫布永遠位於資訊列下方，配合內建 `gap: { top: 0.08, bottom: 0.08 }` 上下邊距保護，達到 100% 物理隔離，無論使用者如何縮放或調整 Y 軸價位，線圖與資訊文字永遠 **0% 重疊、零碰撞**。
   - 透過 `OnCrosshairChange` 即時監聽游標滑移，無縫更新上方平鋪數據，離開時自動恢復當前最新收盤資訊。

2. **自選清單一鍵新建功能 (`WatchlistSidebar.tsx`)**：
   - 解決自選清單過去無法顯眼創建新群組的痛點。
   - 於自選側邊欄頂部顯眼處直接增設「**+ 新建**」操作按鈕，點擊立即展開專業滑入式清單建立面板。
   - 支援「AI概念股、高息ETF、美股科技、核心持倉、觀察名單」等熱門快捷預設標籤，一鍵帶入名稱。
   - 預設提供「**同步加入當前標的**」勾選項，建立新清單同時自動將正在看盤的股票加入，無需額外繁瑣搜尋。
   - 空清單狀態下亦提供「＋ 建立其他自選清單」導引按鈕。

3. **頂部導覽列按鈕精簡為兩大核心分類**：
   - 移除過往按鈕功能重複的「台股、美股、虛擬貨幣」分散切換，整合成「**📊 股票幣圈**」與「**🌐 大盤指數**」兩大清晰分頁。
   - 切換直覺靈敏，在「股票幣圈」下可暢遊台股、美股及加密貨幣，在「大盤指數」下可綜覽全球宏觀金融指標，點擊各大指數直接切入看盤。

4. **右上角清理冗餘全螢幕按鈕**：
   - 依使用者要求刪除右上角冗餘的「全螢幕」按鈕，釋放頂部視窗操作空間，使介面更顯緊湊專業。

## 🚀 v1.4.0 (2026-09-05) - 新手互動導覽教學、K棒資訊點擊固定、現價線自訂開關與圖表層疊修復版

### 🎯 核心改動
1. **全方位彈出式新手功能導覽教學 (`OnboardingModal.tsx`)**：
   - 採用專業金融暗色調視窗（`#181b22`）與零發光高對比設計，為初次進入軟體的使用者提供 6 大功能核心章節介紹：
     - **第 1 章：四大核心市場與全市場秒搜**（台股 2,344 檔官方名冊秒查、美股、全球即時大盤看板、24/7 虛擬貨幣）。
     - **第 2 章：元大證券級專業 K 線看盤體驗**（緊湊防黑邊、頂部平鋪 OHLCV、點擊固定 K 棒、現價線自由開關）。
     - **第 3 章：左側專業繪圖分析工具箱**（磁吸模式 M、趨勢線 Alt+T、水平線 Alt+H、黃金分割 Alt+F、矩形箱體、自訂色盤與獨立記憶庫）。
     - **第 4 章：五大旗艦量化分析工具**（多因子選股器、策略回測中心、個股基本面與估值模型、模擬交易沙盒、價格預警推播，支援導覽內直接一鍵啟動）。
     - **第 5 章：機構級籌碼與 SMC 訂單流**（Volume Profile 籌碼分佈圖、VWAP 成交量加權均價、SMC 機構訂單塊 Order Block、FVG 價值失衡區、BOS 結構突破）。
     - **第 6 章：全域鍵盤極速流與自適應看盤**（/ 全局搜尋、1/5/D/W 週期切換、C 漲跌色調、Tab 切換分頁、F 全螢幕、Esc 清除選取，以及技術指標庫管理與小白百科全書）。
   - **貼心設定**：提供「下次啟動時不再自動顯示」本機記憶選項，並於頂部導覽列提供專屬「新手導覽」按鈕（`HelpCircle`），使用者隨時可重新開啟複習。

2. **紅虛線最新現價水平線 (收盤價反應線) 自訂開關**：
   - 針對使用者回饋「圖表上有一條紅色的線反應最新收盤價無法移除」，於左側專業繪圖工具列正式新增「最新現價線」切換按鈕。
   - 使用者可自由決定是否顯示最新價格水平虛線與刻度標籤，設定自動持久化儲存於 `localStorage`。

3. **K 線圖箱型圖 (K 棒) 點擊固定資訊功能**：
   - 監聽圖表 `OnCandleBarClick` 事件，使用者只要點擊任意一根歷史或當前 K 棒，即可將其「開盤價、最高價、最低價、收盤價、漲跌幅、成交量」固定顯示於左上角獨立 HUD 卡片。
   - 再次點選同根 K 棒、點擊卡片右上角關閉鈕或按下 `Esc` 鍵即可隨時解鎖。

4. **股票名稱與圖表 OHLCV 資訊重疊問題徹底修復**：
   - 解決使用者截圖中股票名稱與上方資訊重疊的問題。
   - 將 KlineCharts 頂部資訊平鋪列垂直偏移設定為 `offsetTop: 46`，使股票身份標籤、OHLCV 數據列與技術指標數值列形成清晰俐落的 3 層垂直梯隊，零重疊、零干擾。

## 🚀 v1.3.0 (2026-09-05) - 臺灣證交所官方全市場名冊自動同步、智慧雙層搜尋與元數據自主學習版

### 🎯 核心改動
1. **臺灣證券交易所 (TWSE) 與櫃買中心 (TPEx) 官方全市場名冊全自動同步**：
   - 解決過去依賴人工手動在字典中建立股票名稱的不可維護性痛點。
   - 撰寫官方 ISIN 國際編碼解析工具（`scripts/syncTwseRegistry.cjs`），全自動獲取台灣全市場 **2,344 檔**上市、上櫃、創新板與 ETF 清單。
   - 檔案僅 165 KB，以 0.1 毫秒（0.0001 秒）極速於本地記憶體內完成全量模糊搜尋，100% 離線可用，絕不消耗外部 API 額度或觸發 Rate Limit。
   - 過去未收錄的「中裕 (4147.TWO)」、「藥華藥 (6446.TW)」、「保瑞 (6472.TW)」、「世芯-KY (3661.TW)」、「元大台灣價值高息 (00940.TW)」等冷門/生技/高價/新掛牌股票，全數支援中文名稱、代號與簡稱秒搜。
2. **金融市場數據自我學習與動態名稱回寫機制 (Auto-Learning Meta Cache)**：
   - 升級 `quoteService.ts` 報價服務，當查詢或加入任何未知或自訂代號時，系統直接從金融行情資料流的 `meta.shortName` / `meta.longName` 動態提取官方公司名稱。
   - 自動將公司真名回寫入本地自選清單與快取，實現「查詢過一次就永久自我學習進化」，無需手動維護任何資料庫。
3. **股票身份辨識全面增強**：
   - 頂部操作列股票代碼（`16px font-black text-white font-mono`）與名稱（`font-extrabold text-slate-100`）顯著化，配備沉穩獨立深色底色與高對比邊框（嚴格恪守無發光、無光暈原則）。
   - 圖表中央加入 TradingView 風格的 4% 灰色浮水印，左上角提供獨立資訊牌，徹底杜絕辨識不清的問題。

## 🚀 v1.2.0 (2026-09-05) - 元大證券風格升級、盤後交易與自適應優化版

### 🎯 核心改動
1. **元大證券風格防黑邊 K 線圖**：
   - 徹底移除 `setLeftMinVisibleBarCount(5)` 與 `setRightMinVisibleBarCount(5)`，改用像素級滾動距離限制 `setMaxOffsetLeftDistance(50)` 與 `setMaxOffsetRightDistance(60)`。
   - 解決向右拖曳導致畫面 95% 呈現全黑空洞的 Bug，蠟燭永遠貼緊邊界並充滿畫布。
   - 將懸浮的黑色方塊 Tooltip 升級為元大證券投資先生標準的頂部平鋪資訊列（`TooltipShowType.Standard`），清晰平鋪「時間、開、高、低、收、漲幅、量」，零遮蔽圖表。
2. **實時時區、未開盤無波動與盤後交易即時追蹤**：
   - 導入國際時區時段判斷引擎 `getMarketSessionStatus`，涵蓋台股、美股、日韓、中港與歐洲各證交所。
   - **已收盤市場 (`CLOSED`)**：狀態標示為 `○ 已收盤`，Sparkline 波動圖呈現冷灰平靜線條（`#64748b`），絕不隨機追加虛假跳動點位。
   - **盤後交易市場 (`AFTER_HOURS`)**：美股 16:00-20:00 EDT 或台股盤後定價時段狀態即時顯示為 `● 盤後交易`（琥珀黃燈），實時追蹤盤後成交點位與波動。
   - **開盤交易市場 (`OPEN`)**：即時跳動顯示 `● 交易中`（翡翠綠燈）。
3. **全球大盤指數「今日領頭羊」下方選項遮蔽修復**：
   - 外層容器補齊 `min-h-0 flex-1`，解決 flexbox 計算溢出。
   - 地區篩選列改為自適應排版（`flex-wrap`），並直接整合快速排序按鈕（**依漲跌幅 / 依點位 / 依5日 / 依振幅** + 升降序箭頭）。
4. **頂部雙層工具列非全螢幕比例自適應**：
   - 四大分類按鈕於小螢幕自動縮寫為 `🇹🇼 台股`、`🇺🇸 美股`、`🌐 大盤`、`🪙 幣圈`。
   - 看盤操作列標的中文名稱在窄螢幕下自動隱藏；週期快捷鍵在小螢幕自動隱藏；籌碼分佈與雙屏分時按鈕自適應縮寫。
5. **劃線工具箱懸浮提示修復**：
   - 移除原生 title 屬性，提示框定點於工具箱右側外緣 10px，搭配 `pointer-events-none` 消除按鈕遮蔽。
