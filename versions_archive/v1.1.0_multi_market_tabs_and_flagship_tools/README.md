# v1.1.0 - 四大市場核心分類與旗艦分析工具整合版

## 📌 版本概述
本版本響應使用者對多市場看盤與深度分析工具的需求，正式導入四大核心市場分類標籤頁、收納式分析工具箱、籌碼分佈與雙屏分時對比系統。

## 📁 包含內容
- [snapshot/src/components/](./snapshot/src/components/)：核心功能模組快照代碼
  - `AlertsModal.tsx`：即時價格與技術指標預警系統
  - `BacktestModal.tsx`：策略歷史回測中心（MA、RSI、MACD 突破與收益率曲線）
  - `FundamentalModal.tsx`：個股基本面診斷與財報雷達
  - `PaperTradingModal.tsx`：虛擬模擬交易下單沙盒
  - `ScreenerModal.tsx`：多維度智慧選股器
  - `WatchlistSidebar.tsx`：自選群組與分市場清單側欄

## 🎯 核心里程碑
1. **頂部四大核心市場分頁**：
   - 「🇹🇼 國內股票」、「🇺🇸 國外股票」、「🌐 大盤指數」、「🪙 虛擬貨幣」切換無發光高對比標籤。
2. **分析工具箱下拉選單**：
   - 整合智慧選股、回測中心、基本面、模擬交易與預警，解決頂部空間擁擠。
3. **專業交易員分析套件**：
   - Volume Profile（籌碼成交量分佈圖）、VWAP（成交量加權均價線）、雙屏分時多週期同屏比對。
