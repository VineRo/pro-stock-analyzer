# ProStock Analyzer 版本封存總目錄 (Version Archives)

本資料夾完整保存了專案從初始設計規範至各歷史版本的文字更迭紀錄與程式碼封存包。

---

## 📂 封存結構說明

1. **版本變更日誌**：
   - [`VERSION_CHANGELOG.md`](./VERSION_CHANGELOG.md)：詳細記錄了 v1.0.0 至最新版本的所有改動、問題修復與核心里程碑。

2. **歷史代碼封存包**：
   - `snapshots_legacy.tar.gz`：已將歷史版本的全量原始碼快照（v1.0 ~ v1.5）完整打包為單一壓縮檔，確保 100% 歷史代碼永久保留，同時避免搜尋引擎或 AI 助手在全文搜尋時產生重複檔案干擾與巨額 Token 消耗。如需提取任一歷史版本的代碼，直接於本目錄執行解壓即可：
     ```bash
     tar -xzf snapshots_legacy.tar.gz
     ```

3. **版本里程碑一覽**：
   | 版本 | 發布階段 | 核心改動與里程碑重點 | 狀態 |
   | :--- | :--- | :--- | :--- |
   | **v1.0.0** | 第一階段 (原型規範) | 建立完整 UI 設計規範與 UX 看盤者動線架構，產出原型應用程式。 | 歷史封存 |
   | **v1.1.0** | 第二階段 (分類與旗艦工具) | 導入四大市場核心分類分頁（台股/美股/大盤/幣圈）、分析工具箱、Volume Profile、回測中心、模擬交易。 | 歷史封存 |
   | **v1.2.0** | 第三階段 (元大升級版) | 元大證券風格防黑邊 K 線圖、實時國際時區與盤後交易追蹤、未開盤無波動、非全螢幕比例自適應。 | 歷史封存 |
   | **v1.3.0** | 第四階段 (全市場名冊與學習) | 官方全市場 ISIN 名冊自動同步 (2,344檔)、0.1ms 極速雙向搜尋、元數據自動學習、股票身份水印強化。 | 歷史封存 |

   | **v1.5.0** | 第六階段 (防重疊外置與自選庫升級) | K線圖資訊列外置防重疊 (0% 碰撞)、自選清單一鍵新建 (+ 新建)、頂部按鈕精簡 (股票幣圈/大盤指數)。 | **目前最新版 (Current)** |

## 🚀 當前版本運行方式

專案根目錄為當前最新原始碼 (`src/` 與 `electron/`)。
```bash
# 啟動 Desktop 桌面視窗
npm run dev:electron

# 或快速啟動
./run.sh
```
