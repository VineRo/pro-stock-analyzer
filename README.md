# 📈 ProStock Analyzer - 專業股票技術分析與新手速成軟體

專為 **「股票分析與交易者」** 量身打造的跨平台（Mac & Windows）桌面技術分析軟體。結合 TradingView 等級的極致流暢 Canvas 繪圖手感、全套主流技術指標庫、**磁吸防手抖畫線**，以及專為股票小白設計的**「技術指標生活化速成百科」**與**「盤面智慧即時診斷」**！

---

## 🚀 零代碼基礎！如何一秒啟動軟體？

您不需要懂任何程式碼，我們已經為您做好了所有一鍵啟動工具：

### 🍎 在 Mac 上運行：
1. 打開終端機或直接找到此資料夾中的 **`run.sh`**。
2. 雙擊執行（或在終端機輸入 `./run.sh`）。
3. 軟體將自動檢查環境，並在數秒內彈出專業原生深色桌面視窗！

### 🪟 在 Windows 上運行：
1. 找到此資料夾中的 **`run.bat`**。
2. 直接雙擊執行 **`run.bat`** 即可。

## ✨ 核心特色與新手友善功能

### 1. 🧲 專業級畫線工具箱與「磁吸模式（Magnet Mode）」
- **告別手抖對不準**：開啟磁吸模式後，游標靠近蠟燭時會自動吸附至最高價、最低價或收盤價，小白也能輕鬆畫出精準趨勢線。
- **豐富工具**：趨勢線、水平支撐壓力線、射線、線段、平行通道、斐波那契回撤（黃金分割）、矩形箱體、文字標註。
- **本地記憶保存**：所有畫線會自動依照股票代碼妥善儲存，重開軟體畫線絕不消失。

### 2. 📖 新手股票技術指標速成百科全書
- 在頂部點擊「**指標百科**」或在指標旁點擊 **`(?)`**，隨時查閱生活化白話文指南：
  - **MA 均線**：全班平均成績比喻、黃金交叉與死亡交叉。
  - **MACD**：快跑與慢跑選手比喻、零軸水上金叉、頂背離抓逃頂。
  - **BOLL 布林通道**：三線道高速公路比喻、上下軌反彈與主升段收口噴發。
  - **RSI 相對強弱**：拔河力道比喻、超買超賣警戒區與鈍化避坑指南。
  - **KDJ / VOL / SAR / ATR / OBV**：完整解析。

### 3. 💡 即時「盤面現況智慧診斷」小幫手
- 頂部常駐智慧分析橫幅，自動綜合比對均線、RSI、布林通道與動能，轉譯成小白一秒看懂的白話文建議：
  - *「多空評分：85分（強烈看多）！股價站穩 5MA 與 20MA 之上，短線動能強勁；但 RSI 已達 78，短線需防超買回檔，切忌盲目追高。」*

### 4. 🎨 靈活配色與多市場支援
- **一鍵切換漲跌配色**：國際標準（綠漲紅跌）⇄ 傳統亞洲習慣（紅漲綠跌）。
- **主流市場覆蓋**：美股（AAPL, NVDA, TSLA, SPY, QQQ 等）、台股（台積電 2330, 鴻海 2317, 聯發科 2454, 0050 等）、主流加密貨幣（BTC, ETH）。
- **除權息還原價格 (Adjusted Close)**：一鍵切換除權息還原走勢，長期技術分析不失真。

### 5. 📊 籌碼成交量分佈 (Volume Profile) & 日內機構 VWAP
- **主力成本線 (POC, Point of Control)**：精確繪製各價位區間籌碼累積量，自動定位 70% 價值區間 (VAH / VAL)。
- **機構 VWAP**：華爾街大戶日內公允成本線，掌握日內多空分水嶺。
- **多週期分屏對比**：支援主副屏雙圖聯動，大週期看方向、小週期找進出場點。

### 6. 🔍 智慧選股與策略掃描器 (Screener)
- 結合多頭突破、均線多頭、RSI 築底超賣、營收高成長 (>15%) 與全市場快速過濾，一秒鎖定優質潛力股。

### 7. 🧪 量化策略回測與歷史檢驗中心 (Backtesting)
- 支援雙均線交叉、RSI 均值回歸、布林軌道突破等多種經典模型。
- 自動計算**總報酬率、歷史勝率、獲利因子 (Profit Factor)、最大歷史回撤 (MDD)** 與繪製資金權益成長曲線 (Equity Curve)。

### 8. 💼 模擬交易實戰帳戶 (Paper Trading) & 基本面體質診斷
- **虛擬本金實戰**：提供 $100,000 虛擬金，支援快捷買賣委託、浮動盈虧即時追蹤與歷史交割單。
- **個股財務體質卡**：查看本益比 (P/E)、股價淨值比 (P/B)、股息殖利率、每股盈餘 (EPS) 與營收年增率。

### 9. 🔔 智慧即時預警通知 (Alerts)
- 支援目標價突破/跌破、RSI 極端超買超賣預警，並聯動系統原生桌面通知提醒。

## 🩺 系統除錯與安心維護機制（給非程式設計師）

- **絕不白屏崩潰**：全系統具備全局錯誤邊界（Error Boundary），即便任何單一數據異常，介面依舊穩健運行。
- **一鍵複製診斷報告**：點擊右上角「**系統健檢（Activity 圖標）**」，若遇到任何問題，點擊「一鍵複製診斷報告」，直接將內容傳給 AI 助理，AI 即可在 10 秒內幫您精準解決！

## 📦 如何打包成 Mac 安裝檔 (.dmg) 或 Windows 安裝檔 (.exe)？

當您想要將軟體分享給其他人，或安裝到其他電腦時：

```bash
npm run build:electron
```
執行完畢後，安裝檔將自動輸出至 **`release/`** 資料夾中：
- Mac：產生 `.dmg` 與 `.zip`。
- Windows：產生 `.exe` 安裝檔與免安裝綠色版。
